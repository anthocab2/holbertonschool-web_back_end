# ES6 Classes

## Description

This project focuses on Object-Oriented Programming in JavaScript using ES6 classes.

The exercises cover how to define classes, create methods, use static methods, extend classes through inheritance, and understand basic concepts related to metaprogramming and symbols.

## Learning Objectives

By the end of this project, I should be able to explain:

* How to define a class
* How to add methods to a class
* Why and how to add a static method to a class
* How to extend a class from another class
* Metaprogramming and symbols

## Requirements

* Ubuntu 20.04 LTS
* Node.js 20.x.x
* npm 9.x.x
* All files must use the `.js` extension
* All files must end with a new line
* Code must pass ESLint
* Tests are executed using Jest
* The entire project can be verified using `npm run full-test`

## Files

| File             | Description                                                        |
| ---------------- | ------------------------------------------------------------------ |
| `0-classroom.js` | Defines a `ClassRoom` class with a maximum student size attribute. |

## Usage

Run a JavaScript test file with:

```bash
npm run dev 0-main.js
```

Run the project tests with:

```bash
npm run test
```

Run all tests and lint checks with:

```bash
npm run full-test
```
