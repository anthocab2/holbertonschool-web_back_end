# ES6 Data Manipulation

## Description

This project focuses on data manipulation in JavaScript using ES6 features and data structures.

The project covers array methods such as `map`, `filter`, and `reduce`, as well as typed arrays and ES6 data structures including `Set`, `Map`, and `WeakMap`.

## Learning Objectives

By the end of this project, I should be able to explain and use:

* `map` on arrays
* `filter` on arrays
* `reduce` on arrays
* Typed arrays
* `Set`
* `Map`
* `WeakMap`

## Requirements

* All files are interpreted on Ubuntu 20.04 LTS
* Node.js 20.x.x
* npm 9.x.x or later
* All files use the `.js` extension
* All files end with a new line
* All functions are exported
* Code must pass ESLint
* Tests are executed using Jest
* The entire project can be verified using `npm run full-test`

## Installation

Install project dependencies:

```bash
npm install
```

## Testing

Run the test suite:

```bash
npm run test
```

Run the complete project verification:

```bash
npm run full-test
```

Run ESLint:

```bash
npx eslint .
```
