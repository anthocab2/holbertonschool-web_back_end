# Python - Async Function

## Description

This project introduces asynchronous programming in Python using `async` and `await`.

The goal is to understand how asynchronous functions work, how to create coroutines, and how to manage tasks that wait for operations without blocking the entire program.

## Learning Objectives

At the end of this project, I am able to explain:

- What asynchronous programming is
- How to write an asynchronous coroutine
- How to use `async` and `await` syntax
- How to use the `asyncio` module
- How to use `asyncio.sleep()`
- How to generate random delays using the `random` module
- How coroutines execute and return values asynchronously
